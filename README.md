# product-show
产品收集展示

## 拾物 · 产品发现库

提交产品官网链接，整理产品介绍、标签和缩略图，建立可搜索、可编辑的产品目录。

### 功能

- 提交链接，提取官网公开介绍与缩略图，并尝试检索补充来源。
- 按关键词匹配标签，提取可识别的功能特点及适用人群；所有内容均可二次编辑。
- 搜索与标签筛选，自适应宽屏卡片布局。
- 点击整张卡片打开详情弹窗。
- 上传并播放 MP4/WebM 产品视频：每个产品最多 5 个，每个文件最大 25 MB。
- 发现并读取公开更新日志，按版本弹窗查看，支持手动补充与修改。
- 展示带统计月份、来源的官网月访问量快照；提供 Similarweb 报告入口。
- 产品记录保存在 D1，视频文件保存在 R2。

### 技术栈

React 19、TypeScript、Vinext/Vite、Tailwind CSS、Shadcn/Radix UI、Cloudflare Workers、D1、R2。

### 开发

需要 Node.js 22.13 或更新版本。

```bash
npm ci
npm run dev
```

构建：

```bash
npm run build
```

这是包含服务端 API 的应用，不能直接部署为 GitHub Pages 静态页面。完整运行需要 Cloudflare Workers 兼容环境与以下绑定：

| 绑定或配置 | 用途 |
| --- | --- |
| DB | D1 数据库，保存产品及视频元数据 |
| BUCKET | R2 存储桶，保存视频文件 |
| SIMILARWEB_API_KEY | 可选；启用官网流量自动同步 |

数据库结构在 `db/schema.ts`；迁移在 `drizzle/`。部署到新环境时需应用迁移，并配置相应绑定。现有 Sites 部署通过 `.openai/hosting.json` 管理；其中的项目标识对应当前网站，复制为新项目时不要复用该标识。

### 目录

- `app/page.tsx`：产品目录与编辑界面
- `components/catalog/`：详情、更新日志、流量展示
- `app/api/`：产品保存、网页解析、更新日志、视频及流量接口
- `lib/`：数据校验、抓取与存储辅助代码
- `db/`、`drizzle/`：数据库定义与迁移
- `worker/`、`build/`：Worker 入口与构建集成

### 当前限制

介绍来自官网公开摘要，标签使用关键词规则，尚未接入大模型总结。网页反爬、登录限制及动态渲染可能导致提取失败；更新日志每次最多提取 30 条可识别版本。自动流量同步需要有效的 Similarweb 授权，未配置时可查看第三方报告并手动录入数据。

本仓库包含源码，不包含线上产品记录、上传的视频、API 密钥或已安装的依赖。视频与数据库不会随着源码自动迁移。
